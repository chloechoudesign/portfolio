JibJab Web Redesign

In late 2024, I led JibJab’s first major web refresh in years. My role centered on expanding the existing design system, redesigning core pages, and creating reusable components that could be used across holidays, promotions, and future features.

The Problem
Structural Limitations of the Legacy Website.
JibJab’s legacy website remained visually consistent for years. The design was familiar, recognizable, and on-brand. But behind the scenes, the pages were built on static templates.
That rigid structure gradually became a bottleneck. Any structural change — like adding a new module or updating layout — required engineering support and weeks of development time.
As JibJab expanded into Starring You AI, JibJab Invites, and new seasonal campaigns, the system couldn’t keep up with the pace. This gap between the brand’s fast growth and the website’s limitations is what triggered the full refresh.
Old Christmas Category Page
The Design Solution
From Static Template to a Scalable Component System.
We quickly realized that updating the interface alone would not solve the underlying bottleneck. Instead of redesigning a single page, we shifted to system thinking and introduced modular, reusable components that marketing could rearrange and scale without engineering support.
This transformed the experience from a fixed template into a flexible framework capable of supporting new campaigns, product types, and features across both the category page and homepage.
Component System
Designing Flexible, Reusable Building Blocks.
We built the system starting with thumbnail components, then scaled it into structured content blocks like Featured, Top 10, Starring You AI, JibJab Invites, and Cast Number. Each block works independently, allowing content and priorities to shift easily based on campaign needs.
System Application
Where the Framework Comes to Life.
The category page was the ideal starting point — it carried high traffic, frequent seasonal updates, and the most structural limitations. By rebuilding this page first, we established a scalable foundation that could extend across the platform.
UX Enhancement
Refining the Category Experience with Filter & Sort.
After establishing the modular category framework, I focused on improving how users browse within it.
The category page includes an “All” section, where users explore the full content library. Previously, filtering in this section was limited to number of people, which became limiting as the platform expanded into new product types like AI Image Packs and Invites.
I redesigned the experience to support filtering across product types and combined Filter & Sort into a single slide-out panel, keeping controls organized in one place and making it easier for users to narrow results without cluttering the page.
Final Designs
Category Page.
The category page transforms a rigid template into a flexible, modular framework. Reusable components and improved browsing tools allow the experience to support evolving campaigns, new product types, and future growth.
Extending the System to the Homepage.
The modular system introduced in the category page also powers the homepage. Reusable content blocks like Featured, Top 10, and Starring You AI allow marketing to shift priorities, promote campaigns, and highlight new features without rebuilding the page.
Phased Rollout & Launch
Launching the System in Stages.
JibJab’s long-term vision is to transition the platform to dark mode. To ensure a smooth transition, the new system was rolled out gradually, starting with the category pages to validate performance, CMS integration, and the modular layout.
While the system was designed with dark mode in mind, the initial release used a lighter theme. This allowed the platform to evolve toward the full design vision over time.
Mobile Optimization
Desktop First, Mobile Adapted.
Because most users accessed JibJab on desktop, the system was designed for desktop first to establish the core layout and components. The same modular system was then adapted for mobile, creating a clean browsing experience on smaller screens.
Outcome & Impact
A System Built for Growth.
The redesign transformed JibJab’s rigid templates into a modular system that can evolve with the product. Reusable components make it easier for marketing to highlight campaigns, promote features like Starring You AI, and adapt seasonal content without structural redesigns.
By creating a flexible foundation, the platform can continue growing while maintaining a consistent experience across pages and devices.
